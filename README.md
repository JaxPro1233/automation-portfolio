# Automation Portfolio

Практическое портфолио из 14 проектов автоматизации: 7 для рынка СНГ и 7 для западного рынка.

Проекты будут реализовываться последовательно — от постановки бизнес-задачи и архитектуры до тестирования, документации и демонстрации результата.
